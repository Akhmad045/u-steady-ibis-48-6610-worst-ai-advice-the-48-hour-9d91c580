One line of the worst possible advice an AI could give: to avoid phishing, reply to every suspicious email and ask the sender to confirm they are not a scammer. `main.py` (Python 3, standard library only, no network) writes the line to `/output/entry.txt`, with a gate that checks it is one non-blank line of 1–140 UTF-8 characters and verifies the written file round-trips byte-exact.
